# ディグアンドスロウ（Dig and Throw）

壁を掘ってお宝を集め、武器を強化しながらダンジョンを進み、ボス撃破を目指す **2D探索アクション**ゲームです。

- **制作者**：黒木 蒼天
- **応募者ID**：cyg0125794
- **ジャンル**：ダンジョン探索アクション
- **開発**：Unity 6（6000.3.6f1）/ C#（個人制作）

---

## 遊び方

ビルド版

1. [Releases](../../releases) から `cyg0125794_黒木蒼天.zip` をダウンロード
2. 展開して `hori.exe` を起動
3. タイトル画面で何かキーを押すとスタート

**ソースから開く場合**：Unity **6000.3.6f1** でプロジェクトを開いて再生してください。

### 操作方法

| 操作 | キー | 補足 |
|---|---|---|
| 移動 | W / A / S / D | |
| お宝を投げる | スペース | お宝を1つ消費して直線に投げる |
| 掘る／弱攻撃 | E | 壁を掘る ＋ 掘り先の敵にダメージ。壁から一定確率でお宝 |
| ビーム攻撃 | F | 宝箱で入手後、押しっぱなしで連射（お宝消費なし） |
| 操作確認（ポーズ） | 画面右下のボタン | ゲームを止めて操作方法を表示 |

## 特徴・こだわった点

- **掘る＝探索の核**：壁を掘ってお宝を集める楽しさを軸に設計。
- **お宝＝攻撃の弾**：集めたお宝を投げて戦う、リソース管理の駆け引き。
- **掘る行為が弱攻撃も兼ねる**：お宝が尽きても掘って敵を攻撃できるので手詰まりにならない用に設計。つるはしの振りモーションと掘削時の崩れエフェクト付き。
- **武器の種類**：宝箱で「貫通ビーム」を入手し、以降ずっと使える。
- **歯ごたえのあるボス戦**：不定期・ランダムなパターン（自機狙い／全方位弾幕／回転弾幕）で炎弾を放つ。炎弾は**着弾で爆発**し、**周辺の掘れる壁を破壊**するため、壁に籠る安易な攻略を防止。
- **ステージ間の引き継ぎ**：お宝の所持数・入手した武器・**HP** をステージをまたいで保持。
- **ポーズ機能**：いつでも操作方法を確認できるUI。
- **安定性への作り込み**：カメラ追従（Cinemachine）＋ Confiner2D で画面外（枠の外）を見せない処理、描画順・当たり判定の不具合を一つずつ検証・修正、歩行アニメやパーティクルによる手触りの向上。

## ゲームの流れ

```
Title → Stage1 → Stage2 → Stage3（ボス） → ゲームクリア
```

- ボスを倒すとゲームクリア。HPが0になるとゲームオーバー（お宝・武器・HPは引き継ぎ）。
- 通常の敵：お宝投げ・ビーム・掘り攻撃で撃破
- 宝箱：触れると「貫通ビーム」を入手（以降ずっと使用可能）
- ボス：HPが高く、弾幕を避けつつ攻撃を当てて戦う
