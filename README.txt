==================================================
　ディグアンドスロウ（Dig and Throw）
==================================================

■ 制作者
黒木 蒼天
応募者ID：cyg0125794

■ ジャンル
ダンジョン探索アクション

■ ゲーム概要
壁を掘ってお宝を集め、武器を強化しながら
ダンジョンを進み、ボスの撃破を目指す
2D探索アクションゲームです。

--------------------------------------------------
■ 起動方法
--------------------------------------------------
同梱の「hori.exe」をダブルクリックで起動します。
タイトル画面で何かキーを押すとゲームが始まります。

--------------------------------------------------
■ 操作方法
--------------------------------------------------
　移動　　　　　… W / A / S / D
　お宝を投げる　… スペース（お宝を1つ消費して直線に投げる）
　掘る／弱攻撃　… E（壁を掘る＋掘り先の敵にダメージ。壁から一定確率でお宝）
　ビーム攻撃　　… F（宝箱で入手後、押しっぱなしで連射。お宝消費なし）
　操作確認・ポーズ … 画面右下の「操作方法」ボタン（ゲームを止めて確認）

--------------------------------------------------
■ ゲームの流れ
--------------------------------------------------
　Title → Stage1 → Stage2 → Stage3（ボス）と進み、
　ボスを倒すとゲームクリアです。
　HPが0になるとゲームオーバー。
　お宝の所持数・入手した武器・HPはステージ間で引き継ぎます。

　・通常の敵：お宝投げ／ビーム／掘り攻撃で撃破
　・宝箱：触れると「貫通ビーム」を入手（以降ずっと使用可能）
　・ボス：HPが高く、炎弾の弾幕を避けつつ攻撃を当てて戦う

--------------------------------------------------
■ こだわった点・工夫した点
--------------------------------------------------
・「壁を掘ってお宝を集める」探索の楽しさを軸にしたゲーム設計
・集めたお宝が攻撃の弾になる、リソース管理の駆け引き
・掘る行為が弱攻撃も兼ねるため、お宝が尽きても手詰まりにならない
　（つるはしの振りモーション＋掘削時の崩れエフェクト付き）
・宝箱で武器が強化される（貫通ビーム）成長要素
・お宝・武器・HPをステージ間で引き継ぐ仕組み
・ボスは不定期・ランダムな弾幕（自機狙い／全方位／回転）で攻撃し、
　炎弾は着弾で爆発して周辺の掘れる壁を破壊（壁に籠る攻略を防止）
・カメラ追従（Cinemachine）＋Confiner2Dで画面外を見せない処理、
　描画順・当たり判定などの不具合を一つずつ検証して修正し、
　安定した動作に仕上げた
・ポーズ中にいつでも操作方法を確認できるUI
